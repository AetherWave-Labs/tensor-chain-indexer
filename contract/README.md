# Tensor Chain Indexer — Contract Workspace

Smart contract development workspace for the Tensor Chain Indexer ecosystem.

This workspace provides the reproducible foundation for Solidity contract development, compilation, testing, and local/testnet deployment.

## Technology

- Hardhat 3
- Solidity 0.8.34
- TypeScript
- Viem
- Node.js test runner
- Ethereum Sepolia for testnet deployment

## Prerequisites

- Node.js 22+
- npm
